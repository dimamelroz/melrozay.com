# Как добавить работу на сайт

## Шаг 1. Подготовь файлы
- Сделай превью-видео работы: 720p, 4–8 секунд, без звука, зациклится автоматически. Вес: 1–3 МБ (максимум 5 МБ).
- Назови файл по правилу: `{id}-preview.mp4`, где {id} — короткое латинское имя работы без пробелов. Например: `dobry-preview.mp4`, `nike-preview.mp4`.
- Положи файл в папку `public/works/`.

## Шаг 2. Узнай Kinescope ID полной версии
- Возьми эмбед-код ролика с Kinescope. В нём есть ссылка вида `https://kinescope.io/embed/XXXXXXXX`.
- ID — это часть после `/embed/`. Например из `https://kinescope.io/embed/fWNV18hpcYBXbTo6icfmiu` ID = `fWNV18hpcYBXbTo6icfmiu`.

## Шаг 3. Добавь работу в файл данных
- Открой файл `src/data/works.ts`.
- Скопируй шаблон ниже и вставь его как новую запись в массив WORKS (между существующими, через запятую).

ШАБЛОН (скопируй и заполни):
```ts
{
  id: "НАЗВАНИЕ-ЛАТИНИЦЕЙ",          // напр. "dobry-cola" — должно совпадать с именем файла превью
  title: "Название работы",          // что видно при наведении, можно по-русски
  role: "DIRECTOR",                  // твоя роль
  projectType: "OLV",                // подпись типа при наведении (Commercial / OLV / Music Video и т.п.)
  filterGroup: "commercial",         // раздел фильтра: "commercial" ИЛИ "music-video"
  orientation: "horizontal",         // "horizontal" (16:9) ИЛИ "vertical" (9:16)
  cover: "/placeholder/work-cover-1.svg",  // запасная картинка (оставь как есть)
  previewVideo: "/works/НАЗВАНИЕ-ЛАТИНИЦЕЙ-preview.mp4",  // путь к превью
  fullVideo: { provider: "kinescope", id: "KINESCOPE_ID" },  // ID из шага 2
},
```

## Шаг 4. Заполни поля
- `id` — латиницей, без пробелов, должно совпадать с началом имени файла превью.
- `title` — название (видно при наведении).
- `role` — твоя роль (DIRECTOR и т.п.).
- `projectType` — что писать при наведении как тип (например OLV, Commercial, Music Video).
- `filterGroup` — в какой раздел попадёт: `"commercial"` или `"music-video"`.
- `orientation` — `"horizontal"` для 16:9, `"vertical"` для 9:16.
- `previewVideo` — путь `/works/{id}-preview.mp4`.
- `fullVideo.id` — Kinescope ID полной версии.

## Шаг 5. Проверь и собери
В терминале:
```
cd ~/Desktop/Projects/dima-melroz-portfolio
npm run build
npx serve out -l 8080
```
Открой localhost:8080, зайди в Works → нужный раздел, проверь работу.

## Важно
- После КАЖДОЙ замены файлов всегда делай `npm run build` заново — иначе увидишь старую версию.
- Имя файла превью ДОЛЖНО совпадать с тем, что в `previewVideo`, иначе будет чёрный экран.
- Делай git commit после каждой успешно добавленной работы.
